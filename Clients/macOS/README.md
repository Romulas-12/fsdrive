# FSDrive для macOS

Застосунок у стилі iCloud Drive: іконка в рядку меню і File Provider-розширення для Finder.
Спільний код (`FSDriveCore`, `FSDriveClientKit`) береться з пакета сервера `../../Server`.

## Розробка в Xcode

Відкрийте `FSDrive.xcodeproj` і запустіть схему **FSDrive**. Теки `App`, `FileProvider` і `Shared` синхронізуються
з проєктом самі: новий файл у теці одразу потрапляє в збірку (`Shared` — в обидві цілі).

## Збірка і встановлення

```bash
scripts/build-mac-app.sh --install
```

Збирає `FSDrive.app` з Xcode-проєкту (Release, лише Apple Silicon — arm64), підписує сертифікатом «Apple Development»
(або `FSDRIVE_SIGN_IDENTITY`), копіює в `/Applications` і запускає.
У налаштуваннях виберіть сервер і увійдіть обліковим записом NAS. Після цього у Finder з'являється розділ **FSDrive** у бічній панелі
(`~/Library/CloudStorage/FSDrive-<сервер>`):

- бібліотеки — теки верхнього рівня, нова тека там — нова бібліотека;
- файли видно одразу, а вміст завантажується при відкритті (значок хмаринки);
- «Завантажити зараз», «Вилучити завантаження» і «Завжди зберігати на цьому Mac» у контекстному меню;
- зміни з інших пристроїв з'являються протягом ~10 с.

App Group і ідентифікатори прив'язані до команди `BBBH2WC2K8` (`Shared/Shared.swift`, `Resources/*`,
`DEVELOPMENT_TEAM` у проєкті). Для іншої команди розробника їх треба замінити.


Запуск із Xcode реєструє в системі ще одну копію застосунку з тим самим ідентифікатором. Скрипт вище
знімає з реєстрації всі копії, крім `/Applications`. Якщо Finder-розширення все одно пише
«Не вдалося під’єднатися» («Local network prohibited» у журналі), перезавантажте Mac: до перезавантаження
macOS тримає доступ до локальної мережі за копією, яку побачила першою.

Розширення для Finder отримує дозвіл на локальну мережу окремо від застосунку: при першому з'єднанні
macOS питає про «FSDriveFileProv», і в «Приватність і безпека → Локальна мережа» з'являється рядок
**FSDriveFileProvider**. Без нього вдома розширення ходить через шлюз. Якщо запит не з'являється, а в
журналі «Local network prohibited», macOS запам'ятала UUID розширення за іншою копією: тоді допомагає
новий UUID (суфікс у фазі «Pin binary UUID» цілі FSDriveFileProvider, зараз `.v2`).
